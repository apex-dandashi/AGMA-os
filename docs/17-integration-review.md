## 2. خريطة الربط العامة ← الداخلية (مُثبتة بالاختبار في جولاتها)

- شكوى موقع ← سجل CMP + إشعار فريق ✔ · تصنيف خصوصية ← تسريب بساعة ٧٢
  مرتبط ✔ · تصنيف أمني ← عدم مطابقة ✔ · متكررة ← زر تحويل CAPA ✔
- تقييم موقع ← صوت العميل (مجهول بلا إذن — الحذف خادمي مُثبت) ✔
- تقديم وظيفي ← APP + إشعار hr/شريك ✔ · درجات خادمية ✔ · سيرة بدلو خاص
  وروابط موقعة ✔ · مواهب ١٢ شهراً ← إخفاء هوية آلي (مهمة يومية) ✔
- وظيفة منشورة ← بوابة ضوابط الوزارة ✔ · إغلاق آلي بالتاريخ ✔ ·
  إيقاف/إعادة نشر يدوي ✔
- lead-intake ← المسار ✔ (منذ المرحلة ٢)
