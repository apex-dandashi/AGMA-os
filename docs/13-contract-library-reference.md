# docs/13 — مكتبة نماذج الاتفاقيات (الدراسة الثالثة، مُقيَّمة)

**المصدر:** «القائمة الكاملة لنماذج الاتفاقيات المقترحة» (أُدخلت 2026-08-07).
تقترح ~75 قالباً + مكتبة بنود + نظام CLM مصغر بشجرة فئة←نوع←قالب←ملحقات.

## ✅ نُفِّذ الآن (P0 بحجم الوكالة)
- **الشجرة بدل القائمة المسطحة:** منشئ العقود صار «فئة ← نوع» (عملاء أساسية /
  سرية / بيانات وإعلانات ومؤثرون) مع تلميح «الحزمة المقترحة» لكل قالب.
- **٦ قوالب جديدة ببنودها الجاهزة:** بيان نطاق العمل SOW (٥ بنود: نطاق،
  تبعيات العميل، قبول، جولتا تعديل، جدول) · أمر التغيير (٤) · معالجة البيانات
  DPA وفق PDPL (٦: الأدوار، النطاق، الأمن و٧٢ ساعة، المعالجون الفرعيون،
  النقل الخارجي بالبنود القياسية، الإعادة والحذف) · تفويض الميزانية الإعلانية
  (٦: السقف والانحراف ١٠٪، مسار الدفع، أتعاب الإدارة منفصلة عن الميزانية،
  ملكية الحسابات للعميل، التقارير، الإيقاف والرصيد) · اتفاقية المؤثر (٧:
  المخرجات، الاعتماد، الإفصاح وترخيص «موثوق»، حقوق الاستخدام ١٢ شهراً
  وWhitelisting، الحصرية ٣٠ يوماً، الإحصاءات، السداد) · السرية الأحادية
  (ديباجة وبند اتجاه مستقلان عن المتبادلة).
- تنبيهات التجديد تشمل الأنواع الجديدة. كل البنود «مسودة مهنية تُعتمد
  بمراجعة محامٍ سعودي» — **قرار شركاء**.

## 🟡 مجدول بشرط
- التوقيع الإلكتروني بسجل إثبات (اسم/وقت/هوية/Hash) → مع بوابة العميل (مرحلة ٧).
- قوالب SCC الأربعة من سدايا للنقل الخارجي → عند أول نقل فعلي خارج المملكة.
- عقود الموردين/المستقلين وHR (بربط قوى لا بديلاً عنه) → مع أول توظيف/تعهيد.
- لوحة متابعة العقود (ARR للعقود، بلا NDA، بلا DPA…) → مع حزمة الرسوم «ج».
- مسار العميل الحكومي → عند أول مناقصة.

## ⛔ متجاوز بحجمه (موثق السبب)
دورة حياة ١٧ حالة بأربع مراجعات · Legal Admin/DPO/Procurement كأدوار مستقلة ·
Delegation Matrix كاملة — يغطيها ثلاثي الصلاحيات + حدود الموافقات + سجل التدقيق.

**نفّذت الدراسة أيضاً توصيتها التقنية:** إصلاح جدول البنود المقلوب في
النماذج، الشعار الحقيقي بدل «AG»، ومنع قطع الصفوف بين الصفحات (وقواعد BiDi
سبق تنفيذها في docs/12).
