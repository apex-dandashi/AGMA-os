# docs/16 — الطبقة العامة: صوت العميل والتوظيف والثقة (الدراسة السادسة، أغسطس 2026)

المصدر: مخطط «الإضافات الاحترافية للواجهة وبوابة الشكاوى والتوظيف الذكي».
أحكام مُقاسة بنمط docs/11–15: ✅ مبني · 🟢 هذه الجولة · 🟡 مؤجل بشرط · ⛔ متروك بسبب.

## المبدأ

ثلاث طبقات متصلة: الموقع ← نماذج عامة محترفة ← AGMA IMS. الشكوى تنشئ
سجل جودة، والتقييم يغذي تحليلات التجربة، والتقديم الوظيفي يدخل ATS —
لا صفحات جميلة منفصلة عن النظام.

## المنفذ في هذه الجولة (🟢)

**صوت العميل**
- فصل صريح: Feedback خفيف (نجوم + جوانب + تعليقان اختياريان، يجوز مجهولاً
  — تقليل بيانات) مقابل Complaint حالة رسمية برقم `CMP-س-٠٠٠٠٠` وتاريخ
  وحالة ومسؤول وSLA داخلي قابل للإعداد (سياسة خدمة لا وعداً نظامياً).
- مسار الشكوى: استلام ← فرز ← إسناد ← معالجة ← حل مقترح ← مغلقة (+ مكررة/
  مسحوبة/مصعّدة) — كل تغيير في سجل التدقيق العام (audit_log).
- **التصعيد الآلي**: تصنيف «خصوصية/بيانات» ينشئ حالة تسريب مرتبطة (ساعة
  الـ٧٢ من لحظة البلاغ = العلم) ويُشعر الحوكمة فوراً؛ «أمن» ينشئ عدم مطابقة
  مصدره حادث + إشعاراً. الشكوى المتكررة تُحوَّل يدوياً بزر إلى عدم مطابقة
  (جذر ← إجراء ← تحقق فعالية) — عملية واحدة لا نظامان.
- تتبع عام لحالة الشكوى بالرقم المرجعي + البريد (يعرض الحالة فقط، لا التفاصيل).

**التوظيف**
- كتالوج أدوار داخلي (أقسام أجما الفعلية) منفصل عن الوظائف المنشورة —
  العام يعرض `PUBLISHED` فقط.
- **بوابة النشر تفرض ضوابط وزارة الموارد البشرية**: لا نشر بلا رمز التصنيف
  السعودي الموحد للمهن + وصف ومهام ومؤهل ومهارات وخبرة + طبيعة العمل
  وساعاته ومزاياه + تاريخا الفتح والإغلاق + استقبال إلكتروني. الإغلاق
  التلقائي بانتهاء `close_date` (المهمة اليومية).
- نموذج تقديم خالٍ من الحقول التمييزية (لا عمر/جنس/حالة اجتماعية/صورة/هوية/
  راتب سابق) + سؤال الترتيبات التيسيرية بصيغته المحايدة ولا يدخل أي تقييم.
- شبكة المواهب بموافقة مستقلة اختيارية (١٢ شهراً — سياسة مقترحة لا مدة
  نظامية) مع إصدار إشعار الخصوصية المحفوظ مع كل طلب.
- روابط أعمال (LinkedIn/GitHub/Behance…) بدل رفع ملفات في المرحلة الأولى —
  أبسط وأسلم (لا مخاطر ملفات من نماذج عامة)، مع تحذير «لا ترفع أسرار
  أصحاب عمل سابقين».

**الموقع**
- Footer مجموعة «الثقة والحوكمة»: الشكاوى والملاحظات، قيّم تجربتك،
  الوظائف، مركز الثقة، الخصوصية، الشروط.
- صفحات: /complaints (شاشة اختيار ثم النموذج) /feedback /careers
  /trust (+ الاستخدام المسؤول للذكاء الاصطناعي + إمكانية الوصول) —
  عربية RTL أولاً، أخطاء نصية واضحة، honeypot + حد معدل.
- **لا شعارات ISO ولا "Certified"** قبل الشهادة الفعلية — صياغة مركز الثقة:
  «نبني وفق متطلبات…» توافقاً تصميمياً لا اعتماداً.

## المؤجل بشرطه (🟡)

| البند | الشرط |
|---|---|
| محرك بنوك الأسئلة الديناميكي (٢٥ بنكاً) والدرجات server-side | عند أول وظيفة منشورة فعلياً — البنية محجوزة (`career_jobs.questions jsonb`) والبنوك محفوظة نصاً في هذا الملف مرجعاً |
| ضوابط المقابلات كـvalidations (دعوة ≥٣ أيام عمل، لجنة ≥٢ بعضو سعودي HR، إبلاغ النتيجة ≤٣٠ يوماً بعدّاد) | عند أول مقابلة رسمية — القواعد موثقة هنا وستُبنى triggers كما بُنيت بوابة النشر |
| Work Samples وScorecards المنظمة | مع أول Shortlist |
| جدول `saudi_occupations` الكامل | يُستورد من المصدر الرسمي عند أول نشر؛ حالياً حقل رمز إلزامي حر |
| قاعدة توطين مهن التسويق (نافذة منذ أبريل 2026) | مراجعة امتثال لكل وظيفة تسويقية قبل النشر — حقل حالة المراجعة موجود |
| رفع CV ملفات (bucket خاص + فحص) | عند الحاجة الفعلية — الروابط تكفي البداية |
| Evidence Registry لأرقام الموقع التسويقية | جولة محتوى مستقلة — كل رقم يربط بدليل |
| CSAT بعد إغلاق المشاريع آلياً | مع بوابة العميل (المرحلة ٧) |
| AI في الفرز (تلخيص/استخراج) | لاحقاً وبقرار بشري دائماً — `AI_AUTO_REJECT=false` مبدأ ثابت |

## المتروك بسببه (⛔)

- **١٩٠ مسمى في الكتالوج**: زُرعت ٢٤ دوراً ممثلة لأقسام أجما الثمانية —
  الإضافة من الإعدادات سطرَ إدخال، لا هجرة.
- **١١ دور صلاحيات جديدة للتوظيف**: أدوارنا تغطي (hr للتوظيف، admin للنشر،
  strategist+ للشكاوى، dpo/legal للتصعيد) — أدوار جديدة عند أول فريق HR.
- **لوحات ATS الاثنتا عشرة**: عدّادات صادقة في التبويبات الآن؛ اللوحات عند
  وجود حجم طلبات يستحقها.

## قرار شركاء
- نص صفحة مركز الثقة والاستخدام المسؤول (مسودات زُرعت — تُراجع قبل الإطلاق).
- تفعيل نشر أول وظيفة (يستلزم رمز التصنيف الرسمي ومراجعة التوطين).
