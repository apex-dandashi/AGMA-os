المصدر: دراسة «مكتبة AGMA الكاملة للعقود والاتفاقيات والنماذج القانونية» —
33 نموذجاً + حقول ذكية + شروط عامة موحدة + قواعد بناء (Snapshot، صلاحيات،
أعلام حمراء، PDF عربي). هذا الملف يسجل حكماً مُقاساً على حجم أجما لكل بند،
على نمط docs/11–13: ✅ مبني · 🟢 نُفذ في هذه الجولة · 🟡 مؤجل بشرط · ⛔ متروك بسبب.

| البند | الحكم |
|---|---|
| الاسم الرسمي «مؤسسة عامر عبدالله بن عثمان الغامدي للخدمات التسويقية» + س.ت 1009127528 طرفاً أول افتراضياً | ✅ ثابت في `packages/legal-templates/src/company.ts` منذ docs/06 (مطابق للسجل المرفوع) |

| الرقم الضريبي لا يُستنتج من السجل | ✅ حقل مستقل (تم توثيقه من الشهادة الضريبية، لا من السجل) |

## 2. تغطية الـ33 نموذجاً

كان مبنياً قبل هذه الجولة (docs/13): عرض سعر (خطاب الارتباط)، MSA، SOW،
NDA متبادلة/أحادية، SLA، عقد صيانة (يغطي «الدعم والصيانة»)، ميثاق تعاون،
أمر تغيير، DPA، تفويض الميزانية الإعلانية، اتفاقية مؤثر (تغطي «إنتاج
المحتوى/المبدع»)، فاتورة/إشعار دائن (خارج مكتبة العقود، مع بند ZATCA QR).

أُضيف في هذه الجولة (🟢 12 نوعاً بعِدّاد CT الموحد):

| النوع | يغطي من الدراسة |
|---|---|
| `service` اتفاقية تقديم خدمات | العقد المستقل للصفقة الواحدة (بدون MSA) |
| `retainer` اتفاقية خدمات شهرية | الحزمة والسعة والترحيل والتجديد |
| `partnership` شراكة وتعاون تجاري | الشراكة الاستراتيجية + التعاون التجاري (نموذج واحد يكفي حجمنا) |
| `contractor` مقاول مستقل | المقاول المستقل/من الباطن + المورد الخدمي (فرد أو مؤسسة) |
| `referral` اتفاقية إحالة | تعريف المحال والعمولة والاستثناءات |
| `licensing` ترخيص محتوى | ترخيص واستخدام المحتوى (نطاق/منصات/مدة/مدفوع) |
| `ip_addendum` ملحق ملكية فكرية | نماذج الملكية الثلاثة والانتقال المشروط بالسداد |
| `acceptance` محضر استلام وقبول | المحضر + تسليم الصلاحيات الرقمية (MFA، مفاتيح، إزالة وصول أجما) |
| `renewal` ملحق تجديد وتمديد | المدة الجديدة والأتعاب وبقاء الأصل |
| `termination` إنهاء (تراضٍ/إشعار) | قالبان على نوع واحد: اتفاقية تراضٍ + إشعار أحادي |
| `settlement` تسوية ومخالصة | نطاق المخالصة المحدد والاستثناءات |
| `authorization` خطاب تفويض | الشخص والنطاق والمدة والإلغاء |

🟡 مؤجل بشرط: **ورقة SCC السعودية** (عند أول نقل دولي فعلي — النص الرسمي
يُلحق دون تعديل، `official_text_locked` — قرار سبق في docs/13) · **إفصاح
التجارة الإلكترونية للمستهلك** (عند أول تعاقد B2C إلكتروني) · **Reseller /
White Label** (لا خط أعمال بعد) · **اتفاقية مورد سلعي** منفصلة (المقاول
المستقل يغطي مورّدي الخدمات؛ التوريد السلعي عند الحاجة).

⛔ متروك: **أمر العمل Work Order** — هو SOW مصغّر تحت MSA وعندنا SOW فعلاً؛
ازدواج القوالب يضر أكثر مما ينفع بحجمنا. **عقود القطاعات (ويب/إعلانات/سوشال/
استشارات/AI) كعقود مستقلة** — نغطيها ببنود خدمة تُنتقى داخل SOW/اتفاقية
الخدمات (بنود المنصات، AI، طبيعة الالتزام)، لا بـ20 عقداً متوازياً.

## 3. الشروط العامة الموحدة

الدراسة تسرد ~35 مادة موحدة. الموجود قبلها: سرية، دفع، ملكية فكرية، خارج
النطاق، صلاحية العرض، بنود SOW (نطاق/التزامات/قبول/تعديلات/جدول). أُضيف
🟢 إلى فئة `legal` (تدخل تلقائياً في العقود الشاملة): طبيعة الالتزام (بذل
عناية لا ضمان نتيجة — المادة ٢٥ من نظام المعاملات المدنية)، منصات الطرف
الثالث وخوارزمياتها، استخدام الذكاء الاصطناعي والمراجعة البشرية، التعليق
لعدم السداد، القوة القاهرة، حدود المسؤولية (بلا إعفاء من غش أو خطأ جسيم)،
الإشعارات والتوقيع الإلكتروني (نظام التعاملات الإلكترونية)، النظام الحاكم
وتسوية النزاعات (تدرج ودي ثم قضاء الرياض)، أولوية النص العربي، الاتفاق
الكامل واستقلال المواد وعدم التنازل، التنازل للغير وعدم إنشاء شراكة ضمنية.

## 4. قواعد البناء

| قاعدة الدراسة | الحكم |
|---|---|
| Snapshot لا ربط ديناميكي بالقالب | ✅ منذ Phase 3: `payload` يُجمَّد نصياً عند الحفظ، والاعتماد يقفله نهائياً (immutability trigger) — تعديل القالب لاحقاً لا يمس عقداً محفوظاً |
| قفل بعد التوقيع + hash + سجل تدقيق | ✅ جزئياً: قفل واعتماد وترقيم وaudit_log مبنية · 🟡 hash للـPDF النهائي وسجل توقيع العميل → المرحلة ٧ (بوابة العميل + التوقيع الإلكتروني بسجل أدلة) |
| الموظف يعدل Instance لا القالب | ✅ مكتبة البنود تحرَّر من الإعدادات (شريك/قانوني فقط)؛ منشئ العقود ينتقي ولا يعدل |
| صلاحيات خمس (Viewer/Editor/Approver/Signatory) | ✅ ممثلة بأدوارنا: الفريق يقرأ، الإدارة التشغيلية تحرر، الاعتماد التجاري للمفوترين، القانوني عبر «المراجعات» (document_reviews) · 🟡 صفة «الموقّع المفوض» كخانة مستقلة → مع التوقيع الإلكتروني في المرحلة ٧ |
| أعلام حمراء على البنود الحساسة | 🟢 نسخة مُقاسة: بند مخصص خارج المكتبة على عقد حساس → تنبيه بطلب مراجعة المستشار القانوني قبل الاعتماد (بوابة المراجعات تمنع الاعتماد أثناء مراجعة معلقة أصلاً) · 🟡 مصفوفة قواعد آلية كاملة عندما يتعدد محررو العقود |
| قواعد DPA الذكية (بيانات شخصية → DPA إلزامي) | 🟢 تلميحات الحزمة على القوالب تصرّح بذلك؛ الإلزام الصلب عند المرحلة ٧ |
| قاعدة التسويق المباشر (موافقة + إيقاف) | 🟢 بند ضمن اتفاقية الإحالة والبنود العامة |
| PDF عربي (RTL + أرقام LTR + خط مضمّن) | ✅ المحرِّكات تبني HTML عربياً بخط مضمّن ولوجو base64، والأرقام/IBAN تُعرض LTR (docs/13 — جولة الطباعة) |
| الحقول الذكية `{{...}}` | ✅ بالمعنى العملي: المنشئ يعبئ الطرفين والتواريخ والأرقام آلياً من العميل وorg_settings؛ لا حاجة لمحرك قوالب نصي منفصل بحجمنا |
