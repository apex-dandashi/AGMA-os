# docs/15 — نظام الإدارة المتكامل AGMA IMS (الدراسة الخامسة، أغسطس 2026)

المصدر: مواصفة «تحويل نظام AGMA إلى نظام إدارة متكامل جاهز للتدقيق والشهادات»
(ISO 9001/27001/27701/22301/20000-1/42001/37301 + PDPL + NCA NCNICC).
أحكام مُقاسة على حجم أجما (فريق صغير) بنمط docs/11–14:
✅ مبني قبل الدراسة · 🟢 نُفذ في هذه الجولة · 🟡 مرحلة لاحقة بشرط · ⛔ متروك بسبب.

## 0. المبدأ المعتمد

«عملية واحدة ← دليل واحد ← ربط بعدة متطلبات» — لا ننشئ أربع مراجعات صلاحيات
لأربع شهادات. البنية many-to-many من اليوم الأول (control_mappings،
evidence_controls)، والمعايير **مُصدَّرة** (framework + version + status) حتى
لا نعيد البناء عند صدور ISO 9001:2026 أو أي تحديث.

وحقيقة صريحة تؤكدها الدراسة نفسها: وجود الشاشات لا يمنح شهادة — الشهادة
تتطلب تطبيقاً فعلياً وأدلة يفحصها مدقق مستقل معتمد (عبر جهة يعتمدها المركز
السعودي للاعتماد).

## 1. ما كان مبنياً قبل الدراسة (يُحسب لصالح الجاهزية)

| متطلب المواصفة | الحال |

## 2. المنفذ في هذه الجولة (Phase 1 — النواة)

- 🟢 **ims_frameworks مُصدَّرة** + بذرة: ISO 9001:2015+Amd1:2024، ISO/IEC
  27001:2022+Amd1:2024، PDPL+اللوائح، NCNICC 1:2025 (استرشادي حتى تعميم
  الهيئة — Applicability محفوظ كحقل لا Hardcode)، ISO/IEC 42001:2023 (مخطط).
- 🟢 **ims_controls** بحقول applicability/implementation_mode/status/owner
  وبذرة ~٢٦ ضابطاً صادقة الحالة (ما يفرضه النظام فعلاً = system_enforced
  بأدلته، وما هو يدوي = manual بوضع «مطلوب»).
- 🟢 **control_mappings** m2m + **evidence** مركز أدلة m2m مع صلاحية زمنية
  (current/expiring/expired تُحسب من valid_until).
- 🟢 **سجل مخاطر موحد** (جودة/أمن/خصوصية/استمرارية/AI/امتثال/مورد) بدرجة
  كامنة ومتبقية محسوبة، وحارس: **قبول خطر حرج/عالٍ للشريك فقط**.
- 🟢 **legal_obligations** بذرة: سجل ROPA (احتفاظ ٥ سنوات بعد الانتهاء)،
  فوترة ZATCA، تجديد السجل، الإقرار الضريبي، مراجعة الوصول الدورية.
- 🟢 **NCR/CAPA** بمسار كامل وقفلٌ مزدوج: لا إغلاق بلا «تحقق فعالية»
  موثّق، **والمتحقق ≠ المالك**.
- 🟢 **ROPA** (processing_activities) بالحد الأدنى النظامي للائحة.
- 🟢 **DSAR** بمهلة ٣٠ يوماً تُحسب آلياً + تمديد ٣٠ بمسوغ مع إشعار صاحب
  البيانات، وتنبيهات أيام 15/23/27/29 وتجاوز.
- 🟢 **privacy_breaches** بعدّاد ٧٢ ساعة من لحظة العلم + تصعيد فوري
  للشريك/مسؤول الخصوصية، وفصلها عن الحادث الأمني (الحادث يولّدها عند وجود
  بيانات شخصية).
- 🟢 **ai_systems** سجل مبدئي (أجما AI-Native — السجل من اليوم كما أوصت
  الدراسة) ببوابة اعتماد بسيطة: مزود/بيانات شخصية/سرية عميل/مراجعة بشرية.
- 🟢 **تنبيهات يومية v6**: مهل DSAR، ساعة التسريب، استحقاق الالتزامات،
  انتهاء صلاحية الأدلة، مواعيد مراجعة الضوابط.
- 🟢 واجهة «**الحوكمة**» في القائمة: نظرة عامة صادقة + الضوابط + المخاطر
  + الالتزامات + الخصوصية + CAPA + الذكاء الاصطناعي.

## 3. المؤجل بشرطه (🟡)

| البند | الشرط/الموعد |
|---|---|
| نصوص ضوابط ISO الكاملة وSoA بنودها | شراء نسخة مرخصة من المعيار (الدراسة نفسها تمنع تضمين النص غير المرخص) — البنية جاهزة للاستيراد |
| Audit Room للمدقق الخارجي | عند التعاقد مع جهة منح — يتطلب حساب قراءة محدود النطاق والوقت (بنية الأدوار تسمح؛ الواجهة عند الحاجة) |
| BIA/خطط الاستمرارية والتمارين (ISO 22301) | Phase 2 — بعد تشغيل النواة ربعاً كاملاً |
| ISO/IEC 27701:2025 فوق طبقة PDPL | Phase 2 — الطبقة الحالية بُنيت على 2025 مفاهيمياً (أدوار متحكم/معالج لكل نشاط) |
| NCA Applicability الرسمي | حقل جاهز؛ التقييم عند تعميم الهيئة أو قرار طوعي |
| ITSM كامل (ISO 20000-1) | Phase 3 — الحوادث التشغيلية حالياً ضمن المشاريع/المشاكل |
| ISO 42001 كامل (تقييمات أثر AI، Evaluations) | Phase 3 — السجل والبوابة موجودان من الآن |
| ISO 37301 وRegulatory Change Management | Phase 3 — legal_obligations النواة |
| Automated Evidence Collectors (تكاملات) | عند توفر مزودين قابلين للربط؛ البنية source=auto محجوزة |
| Audit Pack مولّد + تقارير أسبوعية/شهرية | بعد امتلاء السجلات بربع بيانات حقيقي |
| تقييم أثر المناخ الموحد | حقل في سياق المنظمة عند أول Management Review رسمي |
| DPO Assessment الرسمي | قرار شركاء: إجراء التقييم في الأداة الحكومية (الدراسة ترجح انطباقه على شركات التسويق) — دور dpo موجود في النظام |

## 4. المتروك بسببه (⛔)

- **12 لوحة تحكم منفصلة + تقرير خمس سنوات**: فريق من شخصين — نظرة عامة
  واحدة صادقة الآن، والتقارير عندما توجد بيانات تستحق التقرير.
- **Field-level masking/ABAC كامل**: RLS بالأدوار تغطي حجمنا؛ الإخفاء
  الحقلي عند أول موظف لا يجوز اطلاعه على حقل بعينه.
- **Session anomaly/IP detection وMDM registry**: خارج حجم وأدوات المرحلة.
- **جداول المواصفة الـ١٥٠+ كما هي**: بُني الجوهر الذي يخدم التدقيق فعلاً؛
  كل جدول إضافي يُنشأ عند أول سجل حقيقي له، لا قبله (قاعدة النظام منذ docs/10).
